## Crossword.js     

### About         

Vanilla web app to build and guess crossword/fillword 💎   
  
### Technologies   

Frontend: *TypeScript, Vite, datus.js, codus.js*    
Backend: *PostgreSQL, fs*  
State Management: *Local/Session Storages*             
Unit Testing: *None*      
Deployment: *Vercel*        

### Features        

- Vanilla rendering and routing on client       
- SSE shares word in file      
- Crossword and Fillword     
- Persist data in Local Storage      
- Adding new words to database
